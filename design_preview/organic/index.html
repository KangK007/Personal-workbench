柔壤 · 年轮

一套以「温柔有机」为方向的界面方案：燕麦米底、苔绿行动色、陶土成果色，圆润同心圆角，用留白承担分组职责。 有机形态只编码真实数据——年轮弧表达周期与时长，藤线表达顺序与状态，不做任何装饰性曲线。

目标平台 Windows 桌面 + Android Flutter 3.38.9 / Dart 3.10.8 适配现有 app_theme.dart 58 组对比度实测 · 全部达标 零新增字库

01目标用户的真实操作习惯

先看清人怎么用，再决定界面长什么样。这是本方案所有取舍的依据。

桌面 · 周中晚上规划

2 小时连续操作，多窗口切换，键盘为主，长时间阅读任务与笔记。

界面要求
低视觉噪声；留白用于分组而非装饰；数字必须等宽防抖。

移动 · 白天随手记录

单手、30 秒、掏出即记。记一句、勾一个、放回口袋。

界面要求
拇指可达；主操作下沉；不要求填完整表单。

桌面 · 周末周期回顾

40 分钟浏览一周记录、看趋势、写总结。

界面要求
长文阅读舒适（行长、行高）；时间与序号纵向对齐。

双端 · 打断后回到工作

从通知点进来，想立刻知道「到哪了」，随后回到原处。

界面要求
状态一眼可辨；返回不丢滚动位置与展开状态。

两条不可让步的设计理念

形态纪律
「温柔有机」不是加圆角、换绿色。所有有机形态必须编码真实数据，否则删除。 这条纪律继承原 MASTER.md「不添加船舶、海浪、虚构坐标、装饰编号」的原则——换的是形态语言，不是严谨度。
留白纪律
分组职责由留白承担，线条只做次要提示。组间留白 ≥ 组内留白的 2 倍。即使完全看不见分隔线，结构依然成立。

导航行为规则

四项硬规则
  1. 侧栏只默认展开当前域（手风琴，同时最多一个）。可见决策项从 ~20 降到 6 域 + ≤5 子项。
  2. 域标题整行可点：非当前域＝展开并进入首个子页；当前域＝折叠/展开。
  3. 子项缩进 20px，字重比域标题低一级（域 600 / 子项 400）建立层级，不加装饰。
  4. 深度上限 3 层（域 → 子页 → 页内 Tab），超过即用页内 Tab，不新增导航层。
移动端底部导航：换掉「设置」，补上「成长」

语义纪律（硬规则）

  1. clay 只用于成果与证据，绝不用于错误、警告或危险。
  2. signal 只用于冲突、危险、停止，绝不用于成就或强调。
  3. moss 是唯一的行动色：每个工作面只允许一个 moss 实心主按钮。
  4. 容器底上的文字永远使用对应的 *OnContainer，不直接叠 moss/clay/signal。
  5. 颜色不得作为唯一状态提示，必须同时有形状/图标或文字冗余。
  6. inkFaint 与 divider 是装饰级对比度，禁止承载必须被读到的信息。
为什么柔化线条是安全的

divider 对比度仅 1.3–1.4:1，这是刻意的柔化取向。安全性来自三条兜底：

1 · 留白兜底　组间留白 ≥ 组内 2 倍，看不见线也能分组。
2 · 三重兜底　输入框＝subtle 填充 + borderStrong 描边 + 文字标签。
3 · 焦点兜底　键盘焦点用实色 moss 2px 外环（5.70:1 / 8.17:1），满足 WCAG 1.4.11。

同心圆角规则
当内边距 P < 外层圆角 R 时，内层元素必须使用 r = R − P；当 P ≥ R 时，内层自由使用 control。
例：面板 R=20、内边距 P=8 → 内层必须用 12（20−8=12，恰为 control）。面板 R=20、内边距 P=20 → 已视觉分离，内层自由用 12。

不使用持续环境动画、装饰性漂浮、过长过渡、仅 Hover 可用的关键操作。Flutter 用 MediaQuery.disableAnimationsOf(context)；Web 用 prefers-reduced-motion: reduce，静态终态必须完整可用。

可访问性验收清单

键盘与触控
  • 焦点环：实色 moss 2px + offset 2px；实测 5.70:1（浅）/ 8.17:1（深），满足 ≥3:1
  • 焦点顺序＝视觉顺序；侧栏 ←/→ 折叠，Enter/Space 进入
  • Android 系统返回、底部导航、FAB、侧栏折叠全部可用
  • 触控目标 ≥48dp；视觉圆角不缩小命中区（命中区为矩形）
缩放与动效
  • 支持系统文本缩放到 200%，无遮挡、无截断、无横向滚动
  • 所有容器使用自然高度，禁止固定高度裁切文字
  • prefers-reduced-motion 下终态完整可用
  • 状态不依赖颜色单维表达（三重冗余）

对比度核算方法

L = 0.2126·R_lin + 0.7152·G_lin + 0.0722·B_lin
  c_lin = c / 12.92                 (c ≤ 0.04045)
  c_lin = ((c + 0.055) / 1.055)^2.4   (c > 0.04045)
contrast = (L_亮 + 0.05) / (L_暗 + 0.05)

共核算 58 组配对（浅色 29 + 深色 29），零未达标项。过程中修正了 3 处：浅色 clay 在画布上仅 4.37:1、inkMuted 在输入底上仅 4.20:1、焦点环半透明仅 1.58:1——均已调整至达标。
