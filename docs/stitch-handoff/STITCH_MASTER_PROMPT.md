# MASTER STITCH PROMPT

以下内容可直接粘贴到 Stitch，用于生成“个人工作台”的统一重设计方案。

---

你是一名资深产品设计师、UI/UX 设计师和 Design System Designer。请为现有 Flutter 应用“个人工作台”生成一套完整、可实施、跨 Windows 与 Android 的高保真产品设计。你的任务是重设计现有界面，而不是创建营销网站，也不是重新定义产品。

## 1. 产品定位

“个人工作台”是一款中文优先、本地优先、面向单个知识工作者或研究生的个人管理应用。它将以下真实工作流连接起来：

快速捕获 -> 收件箱整理 -> 任务和项目规划 -> 今日最多三项重点 -> 专注执行 -> 完成证据与任务结算 -> 笔记、日记和周期回顾 -> 目标、习惯和成长记录。

Windows 端承担完整规划、编辑、批量处理、专注和回顾；Android 端承担快速捕获、查看今日、记录习惯、写日记和管理设置。SQLite 是本地事实来源，Supabase 仅提供可选账户与同步。

不要添加团队协作、聊天、AI 助手、第三方日历、完整文件云盘或任何现有产品没有的后端能力。

## 2. 目标用户

为一名同时使用 Windows 和 Android 的中文知识工作者设计。用户有大量任务、项目、研究记录和长期目标，重视：

- 快速捕获，不打断当前工作；
- 明确知道下一步做什么；
- 用键盘高效处理桌面任务；
- 在移动端快速查看和记录；
- 本地数据安全、备份、恢复和同步状态透明；
- 对任务完成、失败、跳过、改期、专注和习惯保留真实证据；
- 高级协议和游戏化功能可选，不能干扰基础流程。

## 3. 设计目标

1. 降低当前多层导航和高功能密度带来的认知负担。
2. 让“下一步”和主操作先于低频配置与统计。
3. 保留所有现有功能、字段、状态、路由和平台差异。
4. 使用渐进披露组织 CTDP、RSIP、国策协议、自律保护、同步和诊断等高级能力。
5. 形成统一、可访问、可响应的设计系统，支持浅色与深色模式。
6. 设计应可由 Flutter Material 3 渐进实现，不依赖玻璃、复杂 3D 或大型新 UI 框架。

## 4. 必须保留的信息架构

### 主导航建议分组

- 工作台：今日、收件箱、专注
- 计划：任务、周视图、任务群、项目、目标
- 记录：笔记、回顾
- 行为：习惯、国策协议、成长
- 系统：自律、设置

### 页面内二级导航

- 任务：全部、收件箱、周视图、任务群
- 项目：概览、任务、任务群、里程碑、笔记与回顾
- 回顾：日回顾、周回顾、月回顾、回顾库
- 行为：习惯追踪、国策协议
- 国策协议：国策树、国策库、轮次历史、高级分析
- 设置：账号与同步、外观与导航、任务与周期、专注与检测、回顾与提醒、通知与后台、诊断与恢复、数据与备份、实验功能、回收站

不要删除兼容页面或改变路由语义。高级协议页面包含 CTDP、RSIP、判例和分析，可作为实验功能入口，不要把它提升为默认核心导航。

### 移动导航

固定五项底部导航：今日、任务、回顾、行为、设置。其余入口放在“更多”面板。保留 Android 系统返回和底部安全区。专注可以从今日或任务直接进入，并在“更多”中提供直接入口。

## 5. 品牌与视觉方向

设计方向名为“有序航行台”：安静、精确、可追溯、适合长时间工作的个人操作界面。保留“个人航行日志”的纸面、墨绿路径和黄铜证据隐喻，但不要做复古装饰或营销化插画。

### 品牌颜色

| Token | Light | Dark | Meaning |
|---|---|---|---|
| Canvas | `#F2F7F3` | `#0F1712` | 页面背景 |
| Surface | `#FBFDFB` | `#16231B` | 面板、菜单、对话框 |
| Ink | `#1B2B20` | `#E8F2EA` | 主文本和图标 |
| Route | `#2F7D57` | `#76C893` | 当前路径、主操作、焦点 |
| Signal | `#C84F45` | `#F07A6F` | 冲突、错误、危险 |
| Marker | `#B8862D` | `#DDB65B` | 已验证完成、证据、里程碑 |

补充中性背景、次级文字和边框色时，从现有 Canvas、Surface、Ink 派生低彩度颜色。确保正文对比度至少 4.5:1，非文本控件和焦点指示至少 3:1。任何状态都同时使用文字、图标或形状，不能只靠颜色。

不要使用紫蓝渐变、米黄色单色主题、玻璃拟态、霓虹、渐变光球、bokeh、过度阴影或彩色仪表盘。

## 6. 字体与排版

- 页面标题：`LXGW WenKai GB`，只用于页面级标题和少量品牌表达。
- 正文、表单、控件：`IBM Plex Sans SC`。
- 时间、倒计时、XP、参数：`IBM Plex Mono`，使用 tabular figures。
- 页面大标题：28 px / 1.3。
- 章节标题：22 px / 1.35。
- 卡片或区域标题：18 px / 1.4，semibold。
- 控件标题：16 px / 1.375，semibold。
- 正文：15 px / 1.5。
- 辅助文字：13 px / 1.35。
- 小标签：12 px / 1.3。

不要随视口宽度连续缩放字号。紧凑工作界面内不要使用 hero 级标题。长中文标题允许两行；按钮文字可换行但不能遮挡相邻元素。

## 7. 间距、圆角与网格

- 间距标尺：4、8、12、16、24、32 px。
- 页面边距：移动 16 px，中等 20 px，宽屏 24 px。
- 面板圆角 6 px；控件 4 px；对话框和底部面板 8 px。
- 图标尺寸：16、20、24、32 px。
- 桌面控件高度约 36 px；Android 触控目标至少 48 x 48 dp。
- 桌面任务行约 44 px，移动任务行约 52 px。

使用实体表面、细边框和极轻阴影。通过留白、对齐、分隔线和文字层级分组。不要把页面区块都做成悬浮卡片，不要卡片套卡片。

## 8. 响应式框架

### 宽屏桌面，>= 1200 px

- 236 px 展开主侧栏。
- 弹性主内容区。
- 仅在确有上下文价值时显示 280–320 px 右侧证据栏。
- 支持键盘快捷键、hover、批量选择、列表/看板和多栏编辑。

### 中等宽度，768–1199 px

- 80 px 图标侧栏。
- 单一主内容区。
- 右侧证据栏变为页面内折叠区或抽屉。
- 不要把桌面三栏直接压缩。

### 移动端，< 768 px

- 单列内容、顶部应用栏、五项底部导航、更多面板和 FAB 快速新增。
- 列表与详情分步进入；长表单使用全屏页。
- 触控目标至少 48 dp，处理底部安全区和 Android 返回。
- 周视图改为日列表；看板改为按状态分段列表；国策树提供分层列表；28 天习惯矩阵提供按周/日期分段的可滚动表格。

## 9. 页面模板

### 执行模板

用于今日、专注、自律。顶部优先显示当前状态、下一步和一个主操作；主体显示实时工作区；右侧或下方显示真实证据、历史和解释。

### 管理模板

用于任务、项目、目标、习惯和国策。顶部为范围、筛选与批量状态；主体为列表、树、矩阵或看板；详情渐进展开。

### 阅读编辑模板

用于笔记、回顾和日记。桌面为索引 + 阅读/编辑双栏；移动端为列表 -> 详情 -> 编辑的分步导航。明确区分查看、编辑和预览。

### 设置模板

桌面为左侧设置分类索引和右侧内容区；移动端为分类列表进入独立详情。每个设置行使用“标题 + 简短说明 + 控件”，危险区独立。提供设置内搜索，但不要虚构远程配置。

## 10. 核心页面要求

### 今日

按以下优先级组织：接下来与开始专注 -> 最多三项今日重点 -> 逾期与今日任务结算 -> 时间块 -> 今日成长证据 -> 日结。保留逻辑日边界说明、替换重点原因、失败原因、完成证据、改期和纠正流程。空状态必须引导开始今日或快速新增。

### 任务

保留全部、收件箱、周视图、任务群。任务行显示状态、标题、最多两项关键元信息和一个上下文主操作；协议、子任务和证据在展开区显示。Windows 保留 Ctrl+A、Shift 范围选择和批量状态/日期/项目/任务群/回收站操作。报告批量部分失败。

### 项目

桌面左侧项目索引，右侧固定项目上下文标题。项目内标签为概览、任务、任务群、里程碑、笔记与回顾；列表/三列看板是任务视图切换，不与页面标签混为一层。保留拖拽，也提供菜单移动。

### 专注

专注中心包含待确认计划、预设、下一承诺和近期记录。专注会话使用大号等宽计时器、开始/暂停/完成，清晰表示正计时或倒计时、应用检测和中断恢复。完成后可添加文本、链接或图片证据。高级协议中断和本地下注必须是可选附加层。

### 自律

顶部明确显示当前平台能力：Windows 可执行进程/网站限制，Android 只编辑与同步。显示当前状态、当前规则、下一次切换、今日拦截和 hosts 健康。规则编辑包含名单模式、默认动作、标题关键词、进程、网站、时段、休息、轮询和强保护。强保护、冷却、紧急码、hosts 修复和管理员权限必须有清晰风险层级。

### 笔记

桌面双栏：左侧索引，右侧 Markdown 阅读/编辑。保留标签、关系和图片附件。未选中、无笔记、附件加载失败和删除恢复均需设计。

### 回顾

顶部为日/周/月范围与日期导航。先显示事实快照，再进入 Markdown 回顾。保留统计变化提醒和手动刷新、旧日记迁移、草稿、跳过、完成、版本、关系和附件。回顾库支持搜索与期间筛选。

### 行为

一级分段为习惯追踪与国策协议。习惯使用 28 天矩阵，状态为完成、跳过、未记录，并保留父子层级和 RSIP 标记。国策协议保留国策树、国策库、轮次历史和高级分析，支持严格模式、维护成本、类型筛选、执行、违反、跳过、计时、关联、移动、强化和归档。高级分析必须标明本地启发式，不表现为科学因果结论。

### 目标

展示目标树、正文、到期日期、里程碑完成状态和关联项目。支持展开/折叠、新建、编辑和空状态。不要把目标页做成装饰性 KPI 仪表盘。

### 设置

必须覆盖：账号与同步、外观与导航、任务与周期、专注与检测、回顾与提醒、通知与后台、诊断与恢复、数据与备份、实验功能、回收站、示例内容和版本信息。备份密码至少 8 位、恢复前预览、本地数据替换确认、导入导出、永久删除二次确认都要保留。Supabase 未配置时显示本地模式，不展示虚假的云状态。

## 11. 跨页面组件

- 应用 Logo：绿色印记形状、页面和路径节点、黄铜证据点；保持小尺寸清晰。
- Page Header：左侧 3 px 路径色竖线，标题、副标题和最多一个主操作。
- Section Heading：标题、可选计数和一个尾部操作。
- Task Row、Project Row、Habit Row、Policy Node、Review Fact Row。
- Solid Panel、Status Pill、Surface Icon、Empty State、Skeleton、Inline Error。
- Filter Bar、Segmented Control、Tabs、Batch Toolbar、Context Menu。
- Quick Capture、Global Search、Record Editor、Attachment Panel。
- Dialog、Bottom Sheet、Full-screen Mobile Editor、Snackbar。
- Timeline、Log Rail、Week Grid、Board、Tree、Matrix。

所有图标优先使用熟悉的 Material/Lucide 类语义图标；不绘制无意义的自定义 SVG。未知图标必须有 tooltip 和可访问名称。

## 12. 交互状态

为每个核心页面和组件设计：default、hover、focus-visible、pressed、selected/current、disabled、loading、empty、success、warning、error、offline、syncing、sync conflict。

- focus-visible 使用清晰的 2 px 焦点环。
- hover 不得改变组件尺寸。
- pressed 可使用 120 ms、0.96 的轻微缩放。
- 状态变化约 180 ms，页面过渡约 220 ms；支持 reduced motion。
- 表单失败保留用户输入。
- 对话框关闭后焦点回到触发元素。
- 拖拽不能是唯一的移动方式。

## 13. 无障碍

- 正文对比度 >= 4.5:1，大文本 >= 3:1，焦点和控件边界 >= 3:1。
- Android 触控目标 >= 48 x 48 dp。
- 所有图标按钮有语义名称；专业缩写首次出现附简短中文解释。
- 支持 200% 文本缩放和 390 px 宽度，不出现文字遮挡或操作丢失。
- 时间表、看板、国策树和习惯矩阵提供列表/表格替代和完整键盘路径。
- 使用 live region 报告搜索数量、批量结果、同步和错误，但避免重复播报。
- 不只用颜色表达完成、失败、冲突、选中或严重程度。

## 14. 文案风格

使用简洁、克制、行动导向的中文。按钮写清动作，例如“开始专注”“保存回顾”“移到回收站”“永久删除”，避免“确定”“好的”等模糊标签。危险操作说明影响和可恢复性。

CTDP、RSIP、hosts、UAC、Supabase 等术语在首次出现时附一行中文解释，并放入高级或诊断上下文。不要声称启发式分析能证明因果，不要把仿真或统计结果写成未经验证的事实。

## 15. 禁止项与实现约束

- 不删除现有功能、字段、状态、路由、键盘行为或 Android 返回行为。
- 不改变任务状态、逻辑日边界、同步冲突、备份恢复、自律规则或成长证据的业务语义。
- 不新增不存在的服务、后端、实时协作、AI 或第三方集成。
- 不用玻璃拟态、渐变 hero、装饰性图表、卡片套卡片、过大圆角或夸张动效。
- 不为了视觉整洁隐藏错误、空状态、权限状态、平台限制或危险操作。
- Android 自律只能编辑和同步规则，不能表现为本机能够终止 Windows 进程或修改 hosts。
- 设计应能映射到 Flutter Material 3 和现有离线字体。
