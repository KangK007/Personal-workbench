# 个人工作台 Page-by-Page Stitch Prompts

本文中的每段提示词可以单独交给 Stitch。所有页面都应继承 [STITCH_MASTER_PROMPT.md](./STITCH_MASTER_PROMPT.md) 的品牌、设计系统、响应式、无障碍和实现约束。

## Page

应用壳层与响应式导航（P0）

## Purpose

为“个人工作台”设计统一的 Windows 与 Android 应用框架，让用户随时知道当前位置、快速新增、全局搜索和同步状态，并能进入全部现有模块。

## Existing Functionality

- Windows 展开侧栏 `236 px`，折叠侧栏 `80 px`。
- 当前可见模块：今日；任务的全部、收件箱、周视图、任务群；项目的概览、任务、任务群、里程碑、笔记与回顾；专注；自律；笔记；回顾的日/周/月；目标；行为；成长；设置。
- 侧栏顶部固定“快速新增”和“全局搜索”，底部显示同步状态。
- 分组支持展开/折叠、方向键、Enter/Space 和选中状态。
- 移动端顶部 AppBar，底部五项导航：今日、任务、回顾、行为、设置；其他模块进入“更多”面板。
- Android 使用系统返回历史；页面状态由 IndexedStack 保留。

## Layout

- 宽屏：236 px 主侧栏 + 弹性主内容 + 页面可选右侧证据栏。
- 中等：80 px 图标侧栏 + 单主内容，右侧栏折叠为抽屉。
- 移动：顶部栏 + 单列内容 + 底部导航 + FAB；更多面板占用安全区域内可用高度。
- 将桌面主导航视觉分为工作台、计划、记录、行为、系统，但保持原路由。

## Components

印记 Logo、用户别名、分组导航、选中指示条、快速新增按钮、搜索按钮、同步状态、折叠按钮、移动底栏、更多面板、FAB、页面切换容器、tooltip。

## Content

使用当前中文名称。折叠模式必须保留图标和 tooltip；移动更多面板显示模块名称和当前页状态。同步状态明确区分本地已保存、同步中、同步成功、同步失败和冲突。

## Interaction

支持点击、键盘方向键、Enter、Space、`Ctrl+K` 和 Android 返回。折叠/展开不丢失当前页面。更多面板选择后关闭并进入页面。快速新增失败时仍停留在表单并保留内容。

## Visual Style

实体纸面、墨绿当前路径、黄铜真实证据、细边框、克制阴影。选中项使用浅绿背景、绿图标和 3 px 左侧指示条，不依赖颜色单独表达。

## States

展开、折叠、hover、focus-visible、当前页、分组展开、同步中、离线、同步失败、冲突、移动更多打开、页面加载、空壳层错误。

## Constraints

不删除任何 `WorkbenchSection`，不改变兼容路由和页面状态保留机制。移动底栏必须保持五项。不要新建营销首页或重复入口。

## Improvements

降低主导航视觉噪声；使用目标分组和稳定二级导航；让当前位置、快速新增、搜索和同步状态比低频子页更容易发现。

## Page

今日（P0）

## Purpose

让用户在打开应用后立刻知道当前逻辑日期、下一步做什么、今日最多三项重点以及哪些任务需要结算，并能直接开始专注或完成日结。

## Existing Functionality

- 页面标题显示“今日”、逻辑日期和逻辑日边界说明；默认语境为 04:00，可在设置中选择 00:00–06:00。
- 桌面显示 04:00–22:00 时间尺；时间块支持与周视图一致的真实时间语义。
- “接下来”显示下一动作并可开始专注。
- 任务区包含逾期待结算、今日、已结算。
- 今日重点最多三项；开始今日可自动选择，也可调整或带原因替换。
- 任务可完成、失败、跳过、改期；失败原因可选模板；完成可添加文本、链接或图片证据；支持结算纠正。
- 支持习惯计划、日结和可选反思；右侧显示今日重点与成长进度。
- 移动端把次要记录折叠到“更多今日记录”。

## Layout

- 宽屏采用“主执行区 + 证据栏”，主区顶部先放“接下来”，然后是今日重点和待结算任务；时间尺作为可扫描的计划背景，不抢主操作。
- 右侧栏宽 280–320 px，只放三项重点状态和今日成长证据。
- 中等宽度将证据栏折叠到主区底部。
- 移动端单列：下一步 -> 今日重点 -> 待处理任务 -> 时间与更多记录 -> 日结。

## Components

Page Header、逻辑日提示、Next Action Panel、今日重点 1–3、任务分组、Task Row、时间尺、结算菜单、证据附件、替换原因对话框、日结面板、成长摘要、Empty State、状态 pill。

## Content

使用真实示例但不要生成虚构统计。主要标签：接下来、开始专注、今日重点、逾期待结算、今日、已结算、调整重点、开始今日、结束今日。失败、跳过、改期和纠正要使用明确中文。

## Interaction

用户可从下一步或任务行开始专注；展开任务查看详情；结算后立即更新分组并给出撤销/纠正入口；替换重点先要求原因；日结前必须处理待结算事项。键盘可以遍历重点、任务和主要操作。

## Visual Style

“下一步”使用 Route 主色形成唯一主焦点；Marker 只标记已验证完成；逾期/冲突使用 Signal 加文本和图标。时间尺轻量、低对比，不做装饰性仪表盘。

## States

今日未开始、已开始、无重点、重点 1/2/3 项、逾期待结算、任务进行中、完成、失败、跳过、改期、无任务、日结完成、证据上传中/失败、逻辑日说明打开、深色模式。

## Constraints

最多三项重点；不能静默替换；不能删除失败原因、证据或结算纠正；不能改变逻辑日边界。移动端不得丢失日结和次要记录入口。

## Improvements

把视觉优先级固定为“下一步 > 重点 > 待结算 > 时间/证据”；减少主区和右栏重复；用渐进披露降低任务行复杂度；空状态只引导开始今日或快速新增。

## Page

任务工作区：全部、收件箱、周视图、任务群（P0/P2）

## Purpose

在一个稳定的任务工作区中完成捕获整理、全部任务管理、周时间规划和任务群编排，同时支持 Windows 高效批量操作与移动端快速处理。

## Existing Functionality

- 顶部页面标题“任务”与当前周信息，二级导航为全部、收件箱、周视图、任务群。
- 全部任务使用可展开 Task Row，支持状态、日期、项目、任务群、收藏、协议、子任务、编辑、专注和移入回收站。
- Windows 支持选择模式、`Ctrl+A`、Shift 范围选择以及批量状态、日期、项目、任务群和回收站操作。
- 收件箱显示快速捕获记录，可编辑、分类和删除。
- 周视图按工作周与时段显示时间块，支持前后周、回到当前、日期选择、新建/编辑/删除、5 分钟吸附和冲突提示。
- 任务群支持串行/并行、成员锁定、移动、移除和跳过；保留旧 CTDP 嵌套组语义。

## Layout

- 固定 Page Header，下方为稳定二级导航；筛选和批量工具条位于内容上方，不与页面标签混在一起。
- 全部/收件箱使用主列表，宽屏可选右侧轻量详情，不强制三栏。
- 周视图占满主内容宽度；左侧时间轴、周一到周五列、当前时间线和冲突层级清晰。
- 任务群桌面使用分组列表或编排视图；移动端使用按组分段的单列列表。

## Components

二级 Tabs、Filter Bar、Task Row、选择框、Batch Toolbar、Status Pill、Context Menu、Inbox Row、Week Grid、Time Block、冲突标记、Task Group Header、成员行、Empty State、Undo Snackbar。

## Content

任务行默认只显示标题和最多两项高价值元信息，例如截止日期、项目或预计时长；其余元数据与 CTDP 协议放入展开区。批量工具条必须显示已选数量。冲突使用“时间冲突”文本，不只用红色块。

## Interaction

保留单选、多选、Shift 范围、Ctrl+A、键盘焦点、上下文菜单和撤销。周视图支持点击空白创建、点击块编辑；拖拽如存在必须有菜单替代。批量请求中避免重复提交，并分别报告全部成功、部分失败和失败。

## Visual Style

任务列表紧凑但可扫描；行高稳定，hover 不位移。选择态和完成态不同：选择用 Route，完成证据用 Marker。时间表使用细网格，当前时间清晰，冲突使用 Signal + 图标/标签。

## States

加载、空列表、无筛选结果、任务展开、选中、多选、批量处理中、部分失败、收件箱为空、周视图无时间块、时间冲突、当前时间、任务群锁定/并行/串行、移动端单列。

## Constraints

不删除任何任务动作、批量语义、5 分钟吸附、冲突状态或任务群规则。不把 CTDP 高级字段默认铺满任务行。不用拖拽作为唯一操作。

## Improvements

把页面导航、筛选和批量模式分成三个明确层级；收缩默认任务行信息；让高级协议只在展开时出现；为周视图和任务群提供移动端专用表达，而不是缩小桌面布局。

## Page

快速新增（P0）

## Purpose

让用户在任意页面以最少输入收下一个任务、笔记、日记或链接，并在需要时进入完整编辑器。

## Existing Functionality

- 桌面使用对话框，移动端使用底部面板。
- 类型为任务、笔记、日记、链接。
- 输入标题和正文，正文最大 2000 字符。
- 提供“完善信息”、取消和“收下”。
- 校验或提交失败时显示就地错误并保留内容。

## Layout

- 顶部使用类型分段控件或紧凑类型选择。
- 主体只显示标题和正文；类型特有的完整字段不在快速新增中展开。
- 底部固定次操作“取消”、可选“完善信息”和主操作“收下”。
- 移动端面板处理键盘、安全区和长文本滚动。

## Components

Type Segmented Control、标题输入、正文输入、字数提示、Inline Error、次按钮、主按钮、关闭按钮、提交进度。

## Content

使用清晰标签，不使用占位符代替外部可见标签。链接类型说明 URL 会在完整编辑器中校验；失败信息说明原因和下一步。

## Interaction

打开时初始焦点进入标题；类型切换保留兼容内容；`Ctrl+Enter` 可提交，Escape/返回遵循关闭确认；“完善信息”把当前内容带入完整编辑器；失败不清空。

## Visual Style

实体表面、8 px 圆角、一个主操作。不要在捕获场景放功能介绍、插图或多层卡片。

## States

默认、四种类型、输入中、达到字数限制、校验错误、提交中、提交失败、提交成功、关闭未保存确认、移动键盘打开。

## Constraints

保留四种类型、2000 字符限制、完善信息和失败保留内容。不新增 AI 自动分类或云端处理。

## Improvements

让类型、最小字段和下一步更明确；为键盘用户提供清晰提交路径；用外部标签和就地错误提高可访问性。

## Page

全局搜索（P0）

## Purpose

让用户通过 `Ctrl+K` 快速查找并打开任务、项目、笔记、日记、链接、目标和其他本地记录。

## Existing Functionality

- 桌面搜索对话框最大约 720x680。
- 输入防抖约 250 ms。
- 查询标题、正文、标签、记录类型和数据值。
- 支持记录种类筛选，当前含笔记筛选能力。
- 结果高亮匹配文本；可编辑记录进入相应编辑器。
- 有初始、加载、无结果、错误和 live region 反馈。

## Layout

- 顶部为搜索输入和可选过滤按钮。
- 中部为按相关性排列的结果列表，显示类型、标题、匹配摘要和关键元信息。
- 底部显示键盘导航提示，但不要用大段教学文字。
- 移动端使用全屏搜索页，不把桌面对话框压缩。

## Components

Search Field、Filter Menu、Result Row、类型图标、匹配高亮、结果计数、Loading Skeleton、Empty State、Error State、键盘选中指示。

## Content

空输入显示最近或建议内容仅在真实数据支持时出现；否则提示“输入关键词搜索本地记录”。无结果显示当前关键词和清除筛选动作。

## Interaction

`Ctrl+K` 打开并聚焦输入；上下键移动、Enter 打开、Escape 关闭；输入后 250 ms 搜索；打开记录后返回原页面上下文。结果数量和错误适度播报。

## Visual Style

搜索框是主焦点，结果列表紧凑、实体、无装饰卡片。高亮必须保持可读，不能只靠背景颜色。

## States

初始、输入中、防抖、加载、有结果、键盘选中、无结果、过滤后无结果、错误、记录已删除、移动全屏。

## Constraints

不虚构远程搜索、AI 语义搜索或不存在的索引。保留本地记录范围、250 ms 防抖、键盘路径和可编辑记录入口。

## Improvements

提升结果类型辨识和键盘选中状态；让筛选条件和无结果原因清晰；减少搜索对话框内的视觉层级。

## Page

项目工作区（P1）

## Purpose

让用户从项目层面组织任务、任务群、里程碑、笔记和回顾，并在列表与三列看板之间切换任务视图。

## Existing Functionality

- 桌面左侧项目列表，支持选择、收藏、数量、编辑和移入回收站。
- 右侧显示选中项目标题与详情。
- 项目内标签：概览、任务、任务群、里程碑、笔记与回顾。
- 任务可在列表与三列看板“待办 / 进行中 / 已完成”间切换和拖拽。
- 显示计数和目标关联；项目软删除后保留关联关系。
- 支持无项目和未选中项目状态。

## Layout

- 宽屏为 260–300 px 项目索引 + 项目内容区。
- 内容区顶部固定项目上下文：名称、状态/收藏、关联目标、一个主操作和更多菜单。
- 项目标签位于上下文标题下；列表/看板切换只在“任务”标签内出现。
- 移动端先展示项目列表，选择后进入项目详情；项目标签可横向滚动或使用下拉，不显示压缩双栏。

## Components

Project Index Row、项目上下文标题、Tabs、List/Board Segmented Control、Task Row、Kanban Column、Task Card、里程碑列表、关系链接、空状态、软删除确认、Context Menu。

## Content

项目列表显示名称、收藏和真实未完成数量。项目标题区说明当前项目，避免用户把项目标签与全局导航混淆。看板卡只显示执行所需元信息，完整协议在详情中查看。

## Interaction

选择项目保留上次标签；列表/看板切换不丢失筛选；拖拽移动状态后给出可撤销反馈，并提供菜单移动替代。删除进入回收站，不表现为永久删除。

## Visual Style

项目索引安静、紧凑；选中项目用 Route 指示。看板列是页面布局，不用三张巨大浮动卡片；列之间以背景、标题和分隔线区分。

## States

无项目、未选中、项目加载、选中、收藏、列表、看板、拖拽中、移动失败、任务为空、里程碑完成、软删除确认、移动端详情。

## Constraints

保留所有项目标签、三列状态、目标关系和软删除语义。不要新增团队成员、权限、评论或协作状态。

## Improvements

明确“全局导航 -> 当前项目 -> 项目标签 -> 任务视图”四层关系；减少嵌套卡片；为看板提供键盘和菜单移动路径。

## Page

专注中心与专注会话（P0）

## Purpose

让用户从今日承诺、任务或专注预设进入一个低干扰的执行环境，并可靠记录暂停、中断、完成证据和会话结果。

## Existing Functionality

- 专注中心显示待确认计划、预设、下一项承诺和近期专注记录。
- 预设支持正计时或自定义倒计时，可绑定主任务。
- 应用检测支持关闭、允许列表、阻止列表和进程清单；可设置一次或每周计划，并在到点置前。
- 专注会话显示大号等宽计时器，支持开始、暂停和完成；结束后发送系统通知。
- Windows 在启用时每 5 秒检查前台应用，并处理休眠/恢复。
- 完成后可添加文字、链接或图片证据。
- CTDP 中断要求继续、按规则处理或判为失败；启用本地激励时可显示下注提示和完成庆祝。

## Layout

- 专注中心：顶部下一承诺和主操作；中部预设列表；下部待确认计划和近期记录。不要让预设空状态占据整屏。
- 专注会话：计时器居中且稳定；任务标题、模式与检测状态在上方；开始/暂停/完成在下方；次要会话信息放侧栏或折叠区。
- 移动端保持计时器与主控制在首屏，证据与高级协议在后续单列区。

## Components

Next Commitment、Preset Row/Card、Scheduled Start Banner、Timer、Mode Label、Start/Pause/Finish Controls、Detection Status、Interruption Dialog、Evidence Editor、Attachment Panel、Session Summary、Recovery Banner、Notification Status。

## Content

明确显示“正计时”或“倒计时”、绑定任务、预计时长、应用检测状态和下一计划。中断对话框写清每个选项的结果。完成证据使用“记录完成证据”，不使用夸张成功口号。

## Interaction

开始后主按钮变为暂停；完成需要明确结束；暂停和应用检测状态实时可见。休眠恢复时说明计时如何处理。CTDP 中断不能被普通关闭绕过。证据上传失败保留文本和会话结果。

## Visual Style

计时器使用 IBM Plex Mono 和稳定宽度，避免数字跳动。专注场景可以减少导航干扰，但不能隐藏退出、暂停、检测和恢复状态。庆祝动画克制且支持 reduced motion。

## States

## Components

Settings Search、Category Navigation、Setting Row、Switch、Segmented Theme Control、Time Picker、Select、Text Field、Sync Status、Account Form、Permission Status、Diagnostic Row、Backup/Restore Flow、Import/Export Actions、Experimental Feature Notice、Trash Selection Toolbar、Danger Zone、Version Footer。

## Content

为每项设置写清“改变什么”和“何时生效”。逻辑日边界明确“仅影响未来生成的周期实例”。本地模式不显示虚假云账户。恢复备份写清会替换本地数据且不会自动覆盖云端。hosts、UAC、Supabase 首次出现附中文解释。

## Interaction

设置搜索定位分类和设置行；开关即时保存时给反馈，失败时恢复并说明。登录/同步状态清晰；备份、恢复预览、导入、永久删除和清空回收站使用分步确认。权限动作显示系统结果。回收站支持选择、全选、批量恢复和部分失败反馈。

## Visual Style

设置是安静的表单/列表，不是重复卡片墙。分类标题与分隔线建立层级；普通设置不使用强色。危险区使用 Signal 边框/图标和明确文本，但不整页铺红。

## States

本地模式、Supabase 未配置、未登录、登录表单、已登录、同步中、成功、失败、冲突；浅/深/系统主题；权限未知/允许/拒绝；hosts 健康/异常/修复中；备份处理中/失败/预览/恢复完成；导入校验失败；实验功能开/关；回收站空/选择/批量处理/部分失败；永久删除二次确认；移动分类/详情。

## Constraints

不得删除任何设置或危险确认。恢复只替换本地数据且不自动覆盖云端。备份密码至少 8 位。Windows 专属能力必须标注平台。前台日志仅本地保留 30 天。不新增订阅、团队管理或不存在的账户能力。

## Improvements

用分类索引和搜索解决长滚动；统一设置行；把平台状态、诊断与危险操作分层；把作用范围和生效时机写进说明；在移动端使用分级导航减少上下文丢失。
