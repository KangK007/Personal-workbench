# 窗口布局复核

更新至：2026-10-14。依据用户的全页面自适应要求检查当前 Flutter 实现；设计 PDF 和 JSON 用作布局参照。页面映射见 `REQUIREMENT_MATRIX.md`，截图对应关系见 `SCREENSHOT_MANIFEST.md`。

## 布局规则

| 范围 | 当前规则 |
| --- | --- |
| 实际内容区 | `WorkbenchViewport` 扣除导航占用，再提供页面断点依据；弹窗保留窗口及软键盘信息。 |
| 超宽工作区 | 整体居中，最大 1480dp；今日两列同时扩展，列间固定 24dp。 |
| 表单与正文 | 表单最多 960dp，长文阅读最多 760dp；不把文字拉满超宽窗口。 |
| 导航 | 窗口宽度 768dp 以下使用紧凑导航；桌面 1200dp 起展开 216dp 侧栏，其余使用 72dp 侧栏；另扣除 1dp 分隔线。 |
| 主从与双栏 | 按实际宽度及文字大小切换；项目、笔记在不足时进入单栏，今日先任务后日程。 |
| 矮窗、大字与键盘 | 内容区域滚动；编辑弹窗保留固定动作区，筛选区按可用高度收缩并可单独滚动。 |
| 少量内容 | 按内容收缩弹窗和卡片；整组两侧余量对称，列表不强行拉高填空。 |
| 图形 | 日历、活动矩阵保留必要的局部滚动；国策图形随容器重新适配，可平移、缩放并重置。 |

## 验证边界

2026-10-14 又逐页目检 35 个审计目标的浅/深色 320×568/200% 文字、800×450/200% 文字及 1200×900 首屏原图对照，发现并收紧月回顾窄窗双位日期的单元格内间距。Windows Release 在隔离空数据库下实际测得 125%/120 DPI、150%/144 DPI、175%/168 DPI，已查看三张应用截图；检查后恢复 100%/96 DPI。当前显示器标准缩放选项最高 175%，200% 需要自定义缩放与注销，因此未实测。

上述全页面覆盖来自 Flutter Widget 测试，数字为测试场景次数；Profile 数字来自 96 DPI 空数据库和上述 600 任务数据库的今日页窗口变换。栅格仍有超预算帧；其他页面大数据、200% 真实 Windows 系统 DPI、任意用户数据组合、完整滚动区域和每个像素的人工验收尚未完成。独立滚动的时间表与大图形属于可操作内容，不视为无意溢出。
