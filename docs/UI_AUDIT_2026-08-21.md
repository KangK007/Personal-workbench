# 个人工作台 · UI/UX 全面审查报告

> 审查日期：2026-08-21
> 审查范围：`lib/ui/` 全部 18 个页面、11 个组件文件、`lib/core/theme/app_theme.dart` 设计令牌体系、导航壳与双端交互形态
> 审查方式：代码级静态审查 + 历史审计文档（`docs/ui-interaction-audit.md`、`UI_AUDIT_CODEX_OPTIMIZATION.md`）交叉验证
> 结论先行：**功能完成度极高（156+ 测试全绿），设计体系三层结构清晰，但存在 3 类系统性问题：玻璃拟态带来的视觉噪声与性能开销、动效体系近乎缺失、跨页面一致性不足。**

## 一、现状全景

### 1.1 规模与结构

| 维度 | 数据 |
|---|---|
| 页面文件 | 18 个（`lib/ui/pages/`） |
| 可区分界面状态 | 约 26 个（14 个顶级页面 + 约 10 个 Tab 级/全屏/浮层子屏幕） |
| 可复用组件 | 11 个文件，三层体系（tokens → 基础组件 → 复合组件） |
| 导航枚举 | `WorkbenchSection` 36 值（含 8 个 legacy 别名） |
| 测试 | 189 个测试全绿，含 15 页面截图审计、12 张金图、紧凑视口回归 |

### 1.2 当前设计体系

**风格定位**：现代专业工作台 + 绿色系玻璃拟态（2026-08-19 全局改版）。
浅色为清爽灰白底（#EDF5EF）+ 翠绿主色（#059669）+ 暖橙点缀；暗色为深墨绿底（#071612）+ 亮翠绿（#34D399）。视觉核心是半透明玻璃面板（BackdropFilter 模糊 + 顶部 1px 高光 + 翠绿外发光）。

**三层组件体系**：
1. **令牌层**：`app_theme.dart` — AppColors（亮/暗各 17 个语义色）+ WorkbenchTokens（ThemeExtension，含 glass* 5 令牌）+ AppSpacing/AppBreakpoints
2. **基础层**：`glass.dart`（GlassSurface）、`common.dart`（PageHeader/SectionHeading/LogSurface/EmptyState/骨架屏/AnimatedNumber/PressScale）
3. **复合层**：`ink_decoration.dart`（SealLogo/装饰件）、`celebration.dart`（FocusCelebration/PulseRing）、TaskRow 等

### 1.3 双端交互形态

- **桌面端**：可折叠树形侧栏（220px 展开 / 80px 折叠）+ `IndexedStack` 懒加载页面堆栈（`_visitedSections` 保持已访问页状态）；Ctrl+K 全局搜索；Ctrl+Shift+Space 系统热键（Windows 残留）
- **移动端**（<768dp）：玻璃 AppBar + NavigationBar 5 目的地（今日/任务/回顾/行为/设置）+ FAB 快速捕获 + "更多"入口页 + `_mobileHistory` 返回栈
- 值得肯定：移动端 PopScope 返回键处理、懒加载保状态、错误初始化兜底视图（`_InitializationErrorView`）均已实现

## 二、问题清单（按严重度分级）

### P0 — 视觉缺陷（直接影响可用性/可读性）

| # | 问题 | 位置 | 详情 |
|---|---|---|---|
| 1 | **头部"绿色脏痕"** | 全部 PageHeader/AppBar/侧栏 | 翠绿 `primary @ 4-5%` 渐变被历史审计判定为脏痕，建议降至 1.5% 以下或移除。本次新方案直接移除所有渐变 |
| 2 | **对比度不足** | 日历网格 / 习惯矩阵 / 成长页 | 日历网格线几乎不可见；28 日习惯矩阵空格与背景 ΔE 仅 2.3；里程碑印章视觉失效 |
| 3 | **底部空屏浪费** | Inbox/Goals/Focus/Growth | 内容不足时底部 60-85% 空白，无空态引导。EmptyState 组件存在但未在这些页面使用 |

### P1 — 体验缺陷（影响日常使用流畅度）

| # | 问题 | 位置 | 详情 |
|---|---|---|---|
| 4 | **动效体系缺失** | 全局 | 全项目仅 4 处显式动画（侧栏折叠、任务行高度、加载指示器、今日页展开）。IndexedStack 页面切换瞬跳无方向感；移动端二级页切换无过渡 |
| 5 | **响应式断点碎片化** | 多个页面 | 页面局部硬编码 620/640/720/800/820/860/900/980 共 8 种阈值，而规范值仅 768/1200。同宽度在不同页面可能触发不同布局，维护成本高 |
| 6 | **头部装饰三种实现** | PageHeader/AppBar/侧栏头部 | 同一语义（页面头部）存在三套不同的装饰实现，视觉不统一 |
| 7 | **卡片/列表项混用** | 跨页面 | 部分页面用 Card 主题，部分用 LogSurface（GlassSurface 包装），任务卡左侧强调竖条有无规则不统一 |
| 8 | **diary 双入口重叠** | diary_page / review 的 diary Tab | 同一功能两个入口，用户心智负担 |
| 9 | **Timer 泄漏式重建** | protocols_page | 每秒常驻 Timer 即使页面不可见也触发 setState 重建，浪费电量与性能 |

### P2 — 一致性/文档/工程质量

| # | 问题 | 位置 | 详情 |
|---|---|---|---|
| 10 | **DESIGN.md 与代码脱节** | DESIGN.md | 装饰透明度写 0.2%-0.3%（实际 15-30%）；H3 字重写 Medium（实际 w600）；卡片阴影描述过时 |
| 11 | **遗留命名与语义脱节** | ink_decoration.dart | InkBrushDivider（无笔触）、BambooSprig（几何圆）、SilkTexture（水平线）、OrientalMark 等均为旧水墨主题残留命名 |
| 12 | **孤儿资源** | pubspec.yaml / assets/fonts | BarlowCondensed 字体未声明未引用；`google_fonts ^6.2.1` 依赖零使用 |
| 13 | **重复实现** | common.dart / ink_decoration.dart | `_bestContrastingText` 两份实现，硬编码色值还不一致（#1A1D29 vs #1A1F1C） |
| 14 | **金图测试可移植性** | test/ | 依赖系统字体 `C:\Windows\Fonts\simhei.ttf`，跨机器不可复现（曾引发抖动） |
| 15 | **文档与代码矛盾** | README / overview.md | "已删除 Windows 代码"的记载与实际残留（hotkey_manager 导入、windows_activity_service、windows/ 目录、packaging/）矛盾 |
| 16 | **超大文件** | policies_page 2048 行 / today_page 1909 行 | 4 个文件超 1200 行，改版与维护成本高（本次不重构，仅记录） |
| 17 | **GlassConfig.blurEnabled 未落地** | glass.dart | 设计的降级开关无任何 UI 入口，恒为 true |
| 18 | **SealLogo 重绘缺陷** | ink_decoration.dart | `shouldRepaint` 漏比较 `accentColor`，主题切换时金色中心点可能不重绘 |

### 玻璃拟态专项评估（本次改版的核心动因）

| 角度 | 评估 |
|---|---|
| 视觉 | 翠绿外发光 + 半透明叠色是"脏痕"问题的根源；模糊使文字与底色对比不可控 |
| 性能 | BackdropFilter 每帧采样背景，移动端滚动列表内使用成本高；需 RepaintBoundary 隔离（已做，但仍是开销） |
| 可控性 | 玻璃效果依赖底层内容，同一面板在不同背景上观感不同，金图测试难以稳定 |
| 结论 | **建议彻底移除**（用户已确认）：实色面板 + 1px 边框 + 微阴影，对比度、性能、可测试性全面受益 |

## 四、改进方向（→ 详见 DESIGN_V2_EMERALD_PRECISION.md）

1. **实色锐利面板**：移除全部玻璃与背景装饰，1px 边框 + 极轻投影双保险制造层次
2. **圆角收紧**：卡片 12→6px、按钮 8→5px，整体气质从柔和转向锐意
3. **密度收紧 15-20%**：列表行 48→44px、分区距 24→20px
4. **动效体系补全**：三级时长标尺（120/200/320ms）+ 页面切换过渡 + 列表交错入场 + 保留并扩展仪式感动效
5. **强调元素纯色化**：渐变竖条/光环/胶囊全部改实心单色
6. **断点统一**：全部页面收敛到 768/1200 两个规范断点
7. **空态全覆盖**：EmptyState 组件推广到 Inbox/Goals/Focus/Growth
8. **保留项**：翠绿主色、墨绿暗底、系统字体+等宽数字、Material Outlined 图标、双主题等价投入
